# 明日汇报指南：把 Jev 放回 Agent 的决策环节

## 建议先讲的结论

当前页面已使用**中文提示词 v3**：任务目标、问题和选项解释均为中文，协议标签保留原 ID，确保调用与比较稳定。两边使用同一份截图和中文证据。中文版全量复测中，两边都是 **25 / 25 项标签命中、22 / 22 次格式有效**；Jev 的端到端响应中位数为 **177.09 ms**，VLM 为 **569.02 ms**。本次 22 对中有 21 对 Jev 更快，多标签场景的一次调用则是 VLM 略快。以下英文 v2 测量已单独留档，不混入中文版本统计。

因此，这次最有依据的展示重点是：**短决策响应更快；一次返回结构化标签与完整模型分数；控制器可以直接使用候选 ID、布尔分数和等级分布，并据此选择接受或弃权。** 当前数据没有证明 Jev 准确率高于视觉 Flash，也不是正式 Qwen3.6-27B 的实验。

## 演示前两分钟

- 本机访问 http://127.0.0.1:8095，打开“汇报清单”。有网络时可以现场重测；已有真实记录随项目保存。
- 右上角切换“汇报模式”，浏览器 F11 全屏。左右方向键切换推荐案例。
- 先说“输入来自受控合成场景，调用与耗时是真实的”。上下文同时给两边，预期标签只用于评测。
- 每个案例先看顶部“当前任务”，再看右侧中文问题与完整候选含义；下方结果会显示中文选项名。
- 模型结果中的回放标识、时间、实际模型名保持可见。不要把历史回放说成现场调用。旧版记录下拉项会显示“英文旧版”，选择后也会提示输入版本差异。
- 下拉框支持鼠标、上下方向键、Home / End、Enter、Esc 和 Tab；弹出与收起均有动画，系统启用“减少动态效果”时会自动关闭动画。

## 8–10 分钟主线

| 顺序 | 案例 | 讲解要点 | 在原框架中的位置 |
|---|---|---|---|
| 1 | 黑屏加载：等待，不重规划 | 一个状态要回答两个问题：能否操作、是否重规划。此类判断常被高频轮询。 | `DecisionJudge.readiness` 与 pipeline 的等待循环 |

| 4 | 关键词相同，论文却不同 | 标题匹配防止走错对象。可切换正确论文对照。 | 论文身份匹配；最终仍由确定性验证器把关 |

| 6 | 四个候选页：选对新标签 | 四张图只选候选 ID；不生成不存在的标签，也不需要从散文抽取 ID。 | `select_opened_tab` |

可追加 1–2 分钟：打开“布尔判断：改动是否已保存”与“有序评分：搜索推进到哪一档”，分别展示 `noul` 和 `score`。前者返回布尔分数，后者返回等级分布与期望值；评分正确性按最高概率等级比较，不拿小数期望值强行对比离散标签。

## 可以直接采用的讲述

> 任务策略模型需要规划和生成动作，但每一步之后还有很多短判断：页面有没有准备好、动作有没有产生预期效果、应该继续走 DOM 还是转向 GUI、下载是否只是开始。我们把这些判断作为独立决策请求，对两种模型提供相同证据。这里两者都能给出正确标签，Jev 在本次部署下返回更快，而且直接提供各候选的分数，便于控制器做接受、等待和弃权决策。

VLM 也可以作为独立验证器运行，并不必然消耗额外的策略步数。不能把“少调用策略模型”说成 Jev 独有能力；更准确的论点是“为这些高频短判断提供合适的接口与可观测的延迟收益”。

上述时间仍包含不同服务器与网络路径的影响，只是此次部署的端到端观测。中文与英文提示词的统计分别呈现，不应将新界面上的中文结果解释成旧版英文测量。

## 连接情况与迁移

已按更正后的 SSH 信息核实：**Jev 运行在 `114.212.10.51` 的 GPU0，显卡为 NVIDIA GeForce RTX 4090 D。** `8007` 监听进程 PID 为 `939290`，与 `nvidia-smi` 报告的 GPU0 模型进程一致；该进程显存约 19026 MiB。实际 API 为 `http://114.212.10.51:8007/v1/systemone`，`/v1/models` 与推理响应均报告 `d3-flash`。远端只做了只读核查，没有修改或重启服务。核查结果见 [部署记录](../reports/deployment-check.json)。

本机 `.env` 已配置可用服务和云端认证；迁移包不包含它。Windows 上请自行填写可访问地址与认证。模型来源可从页面或环境配置切换，历史报告里的地址仅说明当时的来源。

`qwen-flash` 的纯红图探测返回错误颜色且未报告图像 token；`qwen3.6-flash` 返回正确颜色并报告图像 token。正式对比因此使用视觉版 `qwen3.6-flash`，没有将其标记为 Qwen3.6-27B。
