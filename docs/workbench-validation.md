最后一项人工核对：机器人实践 480 / (6 × 2) = 40 元/小时；数据分析 600 / (8 × 2) = 37.5 元/小时。报告明确区分“数据分析每小时更便宜”和“机器人实践总费用更低”，逐项 Jev 覆盖核查均通过。

这些结果验证受控多页面任务，不代表任意公网网站的成功率，也没有覆盖真实桌面定位模型或 Windows 文件管理器。Linux 上使用专用浏览器测试入口；原有 Studio 原生桌面启动器的平台限制未改变。

## 测试中暴露的问题及修复

- 第一轮 CSV 下载在 6 步后失败：输入目标名称尾部空白导致 DOM 语义校验误拒绝。现在对目标与节点名称对称规范化空白，并增加真实浏览器 type + Enter 回归。
- 一轮三课程任务在 18 步耗尽：规划对尚未看到的页面结构作了错误假设，多页采集进展也过早被视为停滞。补充规划约束，并让新正文证据与独立进展核查共同支持采集进度；重复页面仍不能无限延长运行。
- 早期分析报告通过总体核查，但漏答了“总费用谁更低”。现在最终核查按文字交付要求增加覆盖问题；明确遗漏可触发一次报告修订。修订仍失败就保留未通过状态，不能由模型自报成功。
- 原先可视化统计事件被加在 `episode_end` 后，违反轨迹终止事件约定。已改为只向可视化发送该统计事件。

此前失败运行及各轮结果保留在项目上层 `.runtime/workbench-20261018/`，包括 `results-first-pass.json`、`results-second-pass.json`、`results.json` 和 `results-coverage.json`，没有用最终成功覆盖失败记录。
